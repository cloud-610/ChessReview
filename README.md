# 棋局评价 (ChessReview)

chess.com 风格的安卓棋局复盘应用：内置 **Stockfish 19** 官方安卓引擎（universal 二进制，NNUE 网络内嵌），对**每一步棋**给出 11 类评价（妙手/好棋/正招/不错/好/谱着/软招/错招/失误(漏杀)/败招/被强迫）、双方准确率与逐手胜率曲线，支持自由对弈实时评价、PGN 导入复盘、人机对弈、NNUE 模型下载切换与应用自动更新。

## 安装

将 APK 传到安卓手机（Android 5.0+）直接点击安装，允许“安装未知应用”即可。无需任何网络与权限配置即可离线使用。

## 功能

### 棋盘（自由对弈 + 实时评价）
- 双方棋子均可手动走子（点击或拖拽），引擎实时评价：评估条、最佳着法箭头、每步即时徽章
- 悔棋 / 翻转 / FEN 局面载入 / 人机对弈（8 档棋力，Skill Level 0-20）
- 对局自动保存，重新打开应用可继续

### 复盘（棋局评价核心）
- 粘贴或从文件导入 PGN（支持 chess.com 导出格式、注释/变着/NAG 自动剥离）
- 引擎逐局面 MultiPV=2 分析，**每一步**分类：

| 徽章 | 类型 | 判定逻辑 |
|---|---|---|
| `!!` 浅蓝 | 妙手 | 引擎最佳 + 有效弃子(≥1.5子)且保持优势 |
| `!` 深蓝 | 好棋 | 唯一好棋（次佳着法胜率劣化≥12%） |
| ★ 绿 | 正招 | 引擎第一选择 |
| 👍 绿 | 不错 | 胜率损失 <2% |
| ✓ 绿 | 好 | 胜率损失 2–5% |
| 📘 棕 | 谱着 | 命中内置开局库（47 条主流开局主线） |
| `?!` 黄 | 软招 | 胜率损失 5–10% |
| `?` 橙 | 错招 | 胜率损失 10–20% |
| ✕ 粉 | 失误(漏杀) | 原有杀棋/必胜局面(胜率≥92%)被放跑 |
| `??` 红 | 败招 | 胜率损失 ≥20% |
| → 绿 | 被强迫 | 唯一合法着法 / 决定性局面中各着法等价 |

- 胜率换算采用 chess.com 同款公式：`W% = 50 + 50×(2/(1+e^(−0.00368208×cp))−1)`
- 双方准确率（chess.com 近似公式）、11 类徽章统计、关键局面列表、逐手胜率柱状图（点击跳转）、最佳着法/实际着法箭头、中文评注（含“更好的着法”）、带评注 PGN 导出/分享

### 设置
- 引擎参数（实时分析深度、复盘深度、置换表）
- **鳕鱼模型管理**：SF19 内置网络开箱即用；可下载外部 `.nnue` 模型（自定义 URL）并一键热切换（UCI EvalFile）
- **应用自动更新**：版本清单 URL（见下）+ 检查更新 + 系统下载器下载安装；也支持直接输入 APK URL 安装

## 开源许可

- 内置的 Stockfish 19 引擎遵循 **GPLv3**
- 因此本应用整体按 GPLv3 分发；修改与再分发请遵守 GPL 条款

## 已知限制

- chess.com 的确切分类算法未公开，本实现采用社区逆向验证的近似规则（胜率换算公式为其公开同款）
- 界面为高仿风格还原，非像素级复刻
- 评价基于本机引擎深度（默认复盘深度 16），与 chess.com 云端深度的结果可能有差异；可在设置中调深度
- x86/x86_64（模拟器）无官方引擎二进制，仅支持 arm64/armv7 真机
- Android 10+ 出于系统安全限制，从应用数据目录执行外部下载的二进制被禁止，因此**引擎版本升级随应用 APK 更新分发**；NNUE 模型（数据文件）不受影响，可随时下载切换
